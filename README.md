# 🤖 **AutoReiv** — Discord Quest Automator

**AutoReiv** helps you automatically complete any Discord quests and claim rewards without wasting time on routine. Just open the floating panel (`Ctrl+Shift+Q`) and manage quests in one click!

## 🎯 Features
- ✅ **Accept all quests** — automatically accepts available quests.
- ▶️ **Complete all** — emulates video watching, game launching, and streaming to finish quests.
- 🎁 **Claim all rewards** — collects all available rewards for you (with captcha support).
- ℹ️ **Check** — shows a quest summary in a handy notification.
- ⏹️ **Stop** — instantly halts all running tasks.

## 🚀 Advantages
- **Time saving** — no more manually starting streams or games.
- **Farm ORBS Wallet** — accumulate currency to buy **permanent Discord Nitro** and unique visual items in the shop!
- **Convenience** — a floating button is always at hand without interfering with your Discord workflow.

## ⚠️ Important restrictions for users in Russia
- Discord quests may be unavailable without a **VPN**. We recommend using **Cloudflare One Client** version **2026.4.1390.0** with **Traffic and DNS (UDP)** mode. Settings can be customized to your preference.
- If you use **Zapret**, conflicts may occur. In that case, disable Zapret or configure exceptions.
- Every case is individual — choose a method to bypass blocks that suits your network.
